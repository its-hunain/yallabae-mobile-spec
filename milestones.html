Overview

Milestones are sequenced by dependency: nothing in a later milestone is needed to test an earlier one. Each milestone ends with a working build on the stage branch (Android via EAS, iOS once signing is set up) for client review.

Acceptance criteria

  • Sign up, email verification, sign in (email + Google) and sign out work end to end
  • All 19 categories and their subcategories are reachable from the app
  • Filters, sort and search return the same results as the website for the same query
  • Homepage banners, collections, Top Brands and Flash Deals render live Admin data; Top Brands and Featured Collections respect the "Show on Mobile" flag
  • Product Detail shows gallery, variants, seller card, reviews and specifications for any live product
  • Build installable on Android from the stage branch
